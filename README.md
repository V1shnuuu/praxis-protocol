# Praxis Protocol

**An on-chain accountability layer for autonomous AI agents.**

Agents register with a staked bond, commit hashed attestations of every decision
they make, can be challenged and slashed for provably policy-violating behaviour,
and carry a portable on-chain reputation score that any protocol can read.

> Build status: **Phase 1 (contracts) complete.** Phase 2 (agent orchestration
> backend) and Phase 3 (dashboard) follow.

## Why

Autonomous agents are starting to move real value — trading, voting in DAOs,
approving loans — while the only thing backing their behaviour is a prompt and a
promise. Praxis makes that promise economically expensive to break: an agent
publishes a declared policy, bonds capital against it, and commits a
tamper-evident hash of the reasoning behind every action it takes. Anyone can
challenge an action; a resolved challenge burns part of the bond and permanently
marks the reputation.

```
   │  │ ActionAttestation      │  │
   │  │ DisputeSlashing        │  │
   │  │ ReputationScore        │  │
   │  └────────────────────────┘  │

                   ▼
   ┌──────────────────────────────────────────────────────────────┐

```

## Quick start (contracts)

```bash
cd contracts
npm install
cp .env.example .env      # fill in DEPLOYER_PRIVATE_KEY
npm test                  # 66 tests
npm run demo:local        # register → attest → go rogue → dispute → slash
```

See [`contracts/README.md`](contracts/README.md) for the full contract
reference, economics, reputation formula, deployment and PolygonScan
verification steps.
